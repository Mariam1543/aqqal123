# Admissibility of the heuristics (h / true cost-to-go)

Generated by `scripts/admissibility.py`. A ratio above 1 means the heuristic overestimates the true remaining cost, so A\* loses its optimality guarantee.

## Analytic worst case (45-degree diagonal, no obstacles)

| Heuristic | Worst-case h / h\* | Overestimate |
|---|---|---|
| Euclidean (baseline A*) | 1.000 | +0.0% |
| Hybrid alone, Eq. 7 | 1.207 | +20.7% |
| omega x hybrid, Eqs. 6-7 as printed | 1.585 | +58.5% |
| omega x (E+M), V4 | 3.170 | +217.0% |

The bounds with omega hold for nodes no farther from the goal than the start (omega <= ln(1+e) = 1.313). Nodes behind the start get a larger omega.
